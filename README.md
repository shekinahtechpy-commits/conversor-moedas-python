# 💱 Conversor de Moedas em Tempo Real

Projeto desenvolvido pela **Shekinah Tech** para consulta de câmbio atualizado via API.

## 🚀 Funcionalidades
* Consulta de cotação em tempo real (USD, EUR, BTC, etc).
* Conversão instantânea de valores para BRL.
* Interface via terminal simples e intuitiva.

## 🛠️ Tecnologias
* **Python 3**
* **API AwesomeAPI** (Cotações de moedas)
* **Biblioteca Requests**
